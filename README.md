# 元跨境内部 ERP MVP

这是第一版本地静态 MVP，不需要安装依赖。

## 如何打开

直接双击打开：

```text
index.html
```

或在浏览器地址栏打开项目目录下的 `index.html`。

## 演示账号

登录页可以选择不同角色账号，统一密码：

```text
123456
```

内置角色：

- 管理员
- 前端营销人员
- 前端组长
- 后端订单处理人员
- 财务人员

## 已实现的第一版功能

- 登录和角色切换
- 首页近三天冠军展示
- 当天实时业绩排名
- 客户新增和联系方式隐藏
- 客户作废
- 测评订单新增
- 直评和 VP 基础订单字段
- 订单作废
- VP 排单信息复制
- 表格粘贴识别和导入预览
- 直评导入基础识别
- VP 下单要求拆单识别
- 财务待付款自动合计雏形
- 价格模板展示
- 操作日志

## 当前说明

这一版使用浏览器 `localStorage` 保存演示数据。后续正式版会接入数据库和服务端权限。
